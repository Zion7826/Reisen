# 打包运维手册

## 一、打包环境搭建

1. **Python 环境**：确保 Python 3.11 已安装并加入 PATH
2. **创建虚拟环境**：运行 `python create_venv.py`，自动安装所有依赖及 PyInstaller
3. **激活虚拟环境**：运行 `activate.bat`
4. **确认入口文件**：`glass_bottle_defect_gui/main.py` 存在
5. **确认模型权重**：`runs/detect/glass_bottle_defect/weights/best.pt`（可选，缺失则降级）
6. **确认数据配置**：`data.yaml`（必需，缺失则终止打包）

## 二、打包命令

### onedir 模式（推荐）

```bash
python scripts/packaging/build_exe.py
```

产物：`dist/glass_bottle_defect/` 目录 + `dist/glass_bottle_defect.zip` 压缩包

### onefile 模式

```bash
python scripts/packaging/build_exe.py --mode onefile
```

产物：`dist/glass_bottle_defect.exe` 单文件 + `dist/glass_bottle_defect.zip` 压缩包

### 自定义参数

```bash
python scripts/packaging/build_exe.py \
    --name myapp \
    --model path/to/custom_best.pt \
    --data-yaml path/to/data.yaml \
    --skip-verify \
    --skip-compress
```

## 三、产物目录结构

```
dist/glass_bottle_defect/
├── glass_bottle_defect.exe   # 主程序
├── _internal/                # 内部依赖（onedir 模式）
├── best.pt                   # 模型权重（可选）
├── data.yaml                 # 数据配置
├── 使用说明.txt              # 用户文档
└── logs/                     # 运行日志（运行时自动创建）
```

## 四、交付检查清单

- [ ] exe 文件存在且可双击启动
- [ ] GUI 主窗口正常显示
- [ ] 图片上传检测功能可用
- [ ] 摄像头实时检测功能可用（需接入摄像头）
- [ ] 报告导出功能可用
- [ ] 日志文件正常写入 `logs/gui.log`
- [ ] 模型权重加载成功（日志含"模型加载成功"，未进入降级模式）
- [ ] 压缩包体积 ≤ 500MB
- [ ] 启动时间 ≤ 8 秒
- [ ] 在未安装 Python 的干净机器上可正常运行

## 五、常见故障排查

### 1. 隐藏导入遗漏

**现象**：启动报 `ModuleNotFoundError: No module named 'xxx'`

**解决**：在 `scripts/packaging/config/hidden_imports.py` 的对应分组常量中追加模块名，重新打包。

### 2. Qt 插件缺失

**现象**：界面无法显示，报 `This application failed to start because no Qt platform plugin could be initialized`

**解决**：检查 `scripts/packaging/services/dependency_collector.py` 的 `_collect_pyqt5_binaries` 方法，确认 PyQt5 安装路径下 `plugins/platforms` 目录存在。

### 3. 权重加载失败

**现象**：日志显示"模型权重不存在"，进入降级模式

**解决**：
- 确认 `best.pt` 文件存在于打包前路径
- 确认 `config.py` 的 `resolve_resource_root()` 在冻结模式下正确返回 `sys._MEIPASS`
- 检查 spec 文件的 `datas` 段是否包含权重文件

### 4. 磁盘空间不足

**现象**：打包过程中报 `OSError: [Errno 28] No space left on device`

**解决**：清理 `build/` 和 `dist/` 目录，确保磁盘剩余空间 > 2GB。

### 5. 中文路径问题

**现象**：打包或运行时路径相关错误

**解决**：尽量使用英文路径，避免中文和空格。

## 六、交付前必须通过的验证

产物交付前必须通过以下三项检查，未通过禁止交付：

1. **启动验证**：exe 可正常启动，主窗口显示
2. **功能验证**：核心功能（上传、检测、导出）可用
3. **权重验证**：模型权重加载成功，未进入降级模式（或确认降级为预期行为）

使用独立验证脚本：

```bash
python scripts/packaging/verify_artifact.py --artifact dist/glass_bottle_defect
```
