================================================================================
一、项目概述
================================================================================

本项目是一个基于 YOLOv8 深度学习模型的玻璃瓶缺陷检测系统，集成了
PyQt5 桌面 GUI 界面，支持图片上传检测、摄像头实时检测与结果报告导出。

系统可以自动识别玻璃瓶表面的 4 类缺陷：
  - 裂纹 (crack)
  - 气泡 (bubble)
  - 划痕 (scratch)
  - 污渍 (stain)

================================================================================
二、缺陷类别定义
================================================================================

| 类别索引 | 英文名称 | 中文名称 | 检测框颜色 (BGR) | 说明           |
|----------|----------|----------|------------------|----------------|
| 0        | crack    | 裂纹     | (0, 0, 255) 红   | 玻璃表面裂纹   |
| 1        | bubble   | 气泡     | (255, 255, 0) 青 | 透明气泡缺陷   |
| 2        | scratch  | 划痕     | (0, 255, 255) 黄 | 表面划痕       |
| 3        | stain    | 污渍     | (0, 255, 0) 绿   | 表面污渍       |

注意: 类别索引顺序必须与 data.yaml 中的 names 字段保持一致。

五、数据集准备
================================================================================

5.1 数据集目录结构

  datasets/glass_bottle/
  ├── images/
  │   ├── train/      # 训练集图片
  │   ├── val/        # 验证集图片
  │   └── test/       # 测试集图片 (可选)
  └── labels/
      ├── train/      # 训练集标签
      ├── val/        # 验证集标签
      └── test/       # 测试集标签

5.2 标注格式 (YOLO 归一化格式)

  每个 .txt 标签文件每行一个目标，格式为:
    class_id center_x center_y width height

  其中:
    - class_id: 类别索引 (0=crack, 1=bubble, 2=scratch, 3=stain)
    - center_x, center_y: 目标中心点坐标 (归一化到 [0, 1])
    - width, height: 目标宽度和高度 (归一化到 [0, 1])

5.3 数据放置步骤

  1. 将训练图片放入 datasets/glass_bottle/images/train/
  2. 将对应的标签文件放入 datasets/glass_bottle/labels/train/
  3. 图片与标签文件必须同名 (仅扩展名不同)
     例如: 0001.jpg 对应 0001.txt
  4. 验证集同理放入 images/val/ 和 labels/val/
  5. 测试集 (可选) 放入 images/test/ 和 labels/test/

================================================================================
六、模型训练
================================================================================

6.1 基本训练命令

  # 使用默认参数训练 (GPU)
  python train.py

  # CPU 训练 (建议调小 batch size)
  python train.py --device cpu --batch 8

6.2 自定义参数训练

  python train.py \
    --weights yolov8n.pt \
    --data data.yaml \
    --epochs 200 \
    --batch 16 \
    --imgsz 640 \
    --device cuda \
    --workers 8

6.3 参数说明

  --weights  : 预训练权重路径 (默认: yolov8n.pt)
  --data     : 数据集配置文件 (默认: data.yaml)
  --epochs   : 训练轮数 (默认: 200)
  --batch    : 批大小 (默认: 16)
  --imgsz    : 输入图像尺寸 (默认: 640)
  --device   : 训练设备 (cuda/cpu/0,0,1)
  --workers  : DataLoader 工作进程数 (默认: 8)
  --resume   : 从断点继续训练

6.4 断点续训

  python train.py --resume runs/detect/glass_bottle_defect/weights/last.pt

6.5 训练输出

  训练完成后，以下文件将生成在 runs/detect/glass_bottle_defect/:

  - weights/best.pt     : 验证集上表现最佳的模型权重
  - weights/last.pt     : 最后一轮训练的权重
  - results.csv         : 训练过程指标数据
  - train_log.txt       : 详细训练日志
  - confusion_matrix.png: 混淆矩阵
  - PR_curve.png        : 精确率-召回率曲线
  - F1_curve.png        : F1 分数曲线

6.6 评估指标

  训练完成后会自动在验证集上评估，输出以下指标:

  - mAP@0.5       : IoU=0.5 时的平均精度
  - mAP@0.5:0.95  : IoU 从 0.5 到 0.95 的平均精度
  - Precision     : 平均精确率
  - Recall        : 平均召回率
  - 各类别 mAP@0.5: 每类缺陷的单独 mAP

================================================================================
七、模型推理 (检测)
================================================================================

7.1 单张图片检测

  # 基本用法
  python detect.py --image 图片路径.jpg

  # 自定义参数
  python detect.py \
    --image 图片路径.jpg \
    --model best.pt \
    --conf 0.25 \
    --save-dir 输出目录

7.2 参数说明

  --image    : 待检测图片路径 (必需)
  --model    : 模型权重文件 (默认: best.pt)
  --conf     : 置信度阈值 (默认: 0.25)
  --save-dir : 结果保存目录 (默认: 与原图同目录)
  --no-show  : 不弹窗显示结果

7.3 检测结果

  - 结果图片保存为: result_原文件名.jpg
  - 图片上会绘制检测框、类别名称和置信度
  - 控制台输出检测到的缺陷数量和类别分布

================================================================================
八、自动标注
================================================================================

auto_label.py 可以使用训练好的模型对图片进行批量自动标注，
生成 YOLO 格式的标签文件和带标注框的调试图。

8.1 基本用法

  # 使用默认参数 (标注训练集)
  python auto_label.py

  # 指定图片目录
  python auto_label.py --image-dir datasets/glass_bottle/images/train

8.2 自定义参数

  python auto_label.py \
    --model best.pt \
    --image-dir datasets/glass_bottle/images/train \
    --label-dir datasets/glass_bottle/labels/train \
    --debug-dir debug_labels \
    --conf 0.25 \
    --iou 0.45 \
    --img-size 640 \
    --overwrite \
    --limit 10

8.3 参数说明

  --model      : 模型权重文件 (默认: best.pt)
  --image-dir   : 待标注图片目录 (默认: datasets/glass_bottle/images/train)
  --label-dir   : 标签输出目录 (默认: datasets/glass_bottle/labels/train)
  --debug-dir   : 调试图输出目录 (默认: debug_labels)
  --conf        : 置信度阈值 (默认: 0.25)
  --iou         : NMS IoU 阈值 (默认: 0.45)
  --img-size    : 推理图片尺寸 (默认: 640)
  --overwrite   : 覆盖已存在的标签文件
  --limit       : 仅处理前 N 张图片 (0 表示全部)
  --device      : 推理设备 (cuda/cpu)

8.4 输出说明

  - 标签文件: 保存为 YOLO 格式的 .txt 文件
  - 调试图: 保存带检测框的 .jpg 图片，便于人工复核
  - 即使没有检测到目标，也会生成空标签文件 (负样本)

九、GUI 使用说明
================================================================================

9.1 启动 GUI

  python -m glass_bottle_defect_gui.main

9.2 GUI 功能

  1. 图片上传检测
     - 点击"上传图片"按钮选择图片
     - 系统自动进行缺陷检测
     - 结果显示在界面上

  2. 摄像头实时检测
     - 点击"打开摄像头"按钮
     - 实时显示检测画面
     - 点击"关闭摄像头"停止

  3. 结果报告导出
     - 检测完成后可导出报告
     - 报告包含检测图片、缺陷信息等

9.3 降级模式说明

  GUI 默认模型路径为: runs/detect/glass_bottle_defect/weights/best.pt

  如果该文件不存在 (训练前)，GUI 会自动进入降级占位检测模式:
    - GUI 可正常启动和操作所有界面功能
    - 检测结果返回空缺陷列表 (不报错、不崩溃)
    - 日志输出: "模型权重不存在...进入降级占位检测模式"
    - 完成训练后 best.pt 生成，再次启动 GUI 即可自动加载真实检测

  因此: 训练前可以直接启动 GUI 熟悉界面，要获得真实检测结果需先完成训练。

十一、常见问题
================================================================================

Q1: 训练时显存不足怎么办？
A1: 减小 batch size，例如: python train.py --batch 8

Q2: CPU 训练速度太慢？
A2: 建议使用 GPU 训练，或减小 epochs 和 batch size

Q3: 检测结果不准确？
A3:
    - 增加训练数据量
    - 调整置信度阈值 (--conf 参数)
    - 重新训练更多轮次

Q4: GUI 启动后无法检测？
A4:
    - 检查 best.pt 是否存在
    - 查看 logs/gui.log 日志文件
    - 确认已完成模型训练

Q5: 如何导出 ONNX 模型？
A5: 训练时添加 --export_onnx 参数，或使用:
    from ultralytics import YOLO
    model = YOLO("best.pt")
    model.export(format="onnx")
