# 玻璃瓶缺陷智能检测系统

## 一、项目背景与目标

在医药、食品、化妆品等包装行业，玻璃瓶作为最常见的容器形式，其表面质量直接关系到产品安全与品牌信誉。人工质检存在效率低、成本高、标准不统一、疲劳漏检等痛点，而传统机器视觉方案往往只能应对单一缺陷类型，难以满足复杂生产线的综合检测需求。

本项目以"玻璃瓶表面缺陷智能检测"为题，面向工业级质检场景，基于深度学习目标检测框架 YOLOv8 构建了一套从数据准备、模型训练到推理部署的完整解决方案。项目不仅训练出能够同时识别多种缺陷类型的检测模型，还开发了支持实时摄像头动态检测与图片上传静态检测两种模式的 Web 应用界面，实现了从实验室到生产线的端到端落地。

项目的核心目标是：用一套模型覆盖玻璃瓶最常见的四类表面缺陷，做到检得准、检得快、用得起、看得懂，最终为产线质检环节提供可替代人工的自动化方案。

## 二、四类检测缺陷定义

本项目针对玻璃瓶表面最常见的四类缺陷进行检测，类别顺序与数据配置文件保持严格一致，不可随意调整。

第一类是裂纹（crack），指玻璃表面出现的断裂性裂痕，通常由机械应力或温度骤变引起，是影响瓶体结构强度最危险的缺陷。检测时用红色边界框标注。

第二类是气泡（bubble），指玻璃内部或表面残留的透明气泡缺陷，多源于原料杂质或吹制工艺不当，虽不一定影响强度但会降低外观合格率。检测时用蓝色边界框标注。

第三类是划痕（scratch），指瓶体表面的线性擦伤或刮痕，常见于搬运、包装环节的机械摩擦，影响产品外观品质。检测时用黄色边界框标注。

第四类是污渍（stain），指附着在瓶体表面的异物或变色斑点，可能来自环境污染、标签残胶或清洗不彻底，直接影响卫生指标。检测时用绿色边界框标注。

四类缺陷的设定兼顾了结构安全与外观品质两个维度，覆盖了玻璃瓶质检的主要判定项，能够满足大多数包装企业的出厂检验标准。

## 三、系统功能与双模式架构

系统提供两种检测模式，用户可通过顶部标签栏自由切换，两种模式共享同一套模型与样式，操作体验统一。

第一种是实时画面检测模式。该模式通过 OpenCV 调用本地摄像头，逐帧捕获画面并送入 YOLOv8 模型推理，检测结果通过 MJPEG 视频流实时推送到浏览器前端显示。画面中会实时绘制缺陷边界框、类别名称与置信度，左上角显示当前帧率 FPS，右侧设有检测日志滚动列表，便于操作人员直观掌握检测动态。该模式适用于产线在线检测场景，可将摄像头固定在瓶体流转工位，实现不停机连续质检。

第二种是图片上传检测模式。该模式支持点击选择或拖拽上传，可一次性传入多张图片。系统逐张推理后将原图与标注结果图并排展示，每张图片单独统计缺陷数量与类别分布，底部汇总所有图片的总缺陷数。该模式适用于抽检、复检或离线批量分析场景，质检员可随时上传可疑图片进行复核。

两种模式均支持结果保存：实时模式可随时截图保存当前画面，上传模式可保存标注后的结果图。所有结果默认存放到输出目录，便于后续追溯归档。

## 四、技术实现与训练策略

项目以 Ultralytics 官方 YOLOv8n 为基础模型进行迁移学习，采用 AdamW 优化器，初始学习率设为 0.001，输入图像尺寸 640，置信度阈值 0.25，IOU 阈值 0.45，兼顾检测精度与推理速度。

在数据层面，项目引入了 MVTec AD 公开数据集的 bottle 子集作为补充训练数据，并编写了数据集转换脚本，将 MVTec 提供的缺陷掩码自动转换为 YOLO 归一化标注格式。转换过程中通过轮廓提取与边界框计算，将像素级掩码转化为目标检测所需的矩形框标注，并按 80% 训练、20% 验证的比例随机划分数据集。

在训练策略上，项目采用多轮渐进式训练方案。第一轮以标准学习率进行基础训练，后续每轮将学习率减半并增加训练轮数，使模型在全局最优附近逐步精细微调。同时启用了丰富的数据增强策略，包括旋转、平移、缩放、剪切、左右翻转、Mosaic 拼接、Mixup 混合、Copy-Paste 复制粘贴以及色调饱和度明度扰动，有效缓解了小样本场景下的过拟合问题，提升了模型对缺陷形态多样性的泛化能力。

训练完成后系统自动在验证集上评估，输出 mAP@0.5、mAP@0.5:0.95、平均精确率与召回率四项核心指标，并按类别分别统计，便于定位薄弱缺陷类型并针对性优化。

## 五、项目优势与创新点

第一，双模式一体化设计。同一套模型、同一套界面同时支持实时动态检测与静态图片检测，无需切换程序或重复部署，降低了系统复杂度与使用门槛，适应在线与离线两种质检场景。

第二，渐进式多轮训练策略。通过逐轮降低学习率、增加训练轮数的方式，使模型从粗到细逐步逼近最优解，相比单次长训练能获得更稳定的收敛效果，尤其适合训练样本有限的工业缺陷检测任务。

第三，自动化的数据集转换流程。针对 MVTec AD 这类以异常检测格式发布的数据集，项目编写了掩码到 YOLO 标注的自动转换脚本，一键完成格式转换与数据划分，大幅降低了数据准备的工作量，也为其他 MVTec 数据集的复用提供了通用方案。

第四，完善的降级容错机制。当模型权重文件不存在时，系统不会崩溃报错，而是自动进入降级占位模式，界面功能全部可操作，检测结果返回空列表并给出日志提示。这一设计保证了开发调试阶段界面先行、模型后补的灵活工作流。

第五，全栈技术自主可控。从数据准备、模型训练、推理服务到前端界面，全部基于 Python 技术栈实现，依赖开源框架，不依赖任何商业 SDK 或云服务，便于私有化部署与二次开发。

## 六、实际应用价值与展望

在医药包装领域，玻璃瓶作为注射剂、口服液、疫苗等产品的核心包装材料，其表面缺陷可能导致药品污染或剂量不准，质检环节不可有丝毫疏漏。本系统可部署在灌装线、包装线的视觉检测工位，对每一只瓶体进行毫秒级自动检测，不合格品即时剔除并记录缺陷类型与位置，为质量追溯提供数据支撑。

在食品饮料行业，玻璃瓶重复使用前需经过严格的外观检验。传统人工灯检依赖经验且容易疲劳漏检，本系统可替代人工实现 7×24 小时不间断检测，显著降低人力成本与漏检率，同时统一检测标准，避免人为判定差异。

在化妆品包装领域，外观品质直接影响品牌形象，划痕、气泡等微小缺陷都可能导致消费者退货。本系统的高灵敏度检测能力可捕捉人工难以发现的细微缺陷，提升出厂合格率与品牌口碑。

展望未来，系统可在以下几个方向持续演进：一是扩充缺陷类别，增加缺口、变形、偏壁等更多缺陷类型，覆盖更完整的质检标准；二是引入缺陷严重程度分级，根据缺陷尺寸与位置自动判定是否需要剔除，实现智能决策而非简单检出；三是对接 MES 与 ERP 系统，将检测数据回流至生产管理系统，形成质量数据闭环，驱动工艺持续改进；四是探索模型轻量化与边缘部署，通过 ONNX 导出与 TensorRT 加速，将推理延迟压缩至毫秒级，满足高速产线的实时性要求。
